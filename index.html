Projeto 1

Loja do JK — Loja fictícia inspirada nos looks do Jungkook (BTS)

A Loja do JK é um projeto de front-end criado para treinar habilidades em HTML e CSS, simulando uma loja virtual moderna. O site apresenta uma interface limpa e organizada onde o usuário pode navegar por uma coleção de roupas inspiradas nos looks reais do Jungkook (BTS).

O projeto conta com:

  • Layout totalmente responsivo
  • Header fixo com navegação simples
  • Seção de destaque (hero) com chamada
    • principal
  • Grade de produtos com cards estilizados
  • Formulário de contato funcional (HTML)
  • Design inspirado em e-commerce real, incluindo botões interativos e sombras suaves
  • Arquitetura organizada com HTML semântico e CSS modular

    • Este projeto foi desenvolvido apenas para prática, mas simula a estrutura de uma loja real, trabalhando conceitos como composição visual, responsividade, tipografia e identidade estética.

    Projeto 2

    📝 Descrição do Projeto — Site Pessoal “Edgar Dev”

    O Edgar Dev é um site pessoal desenvolvido utilizando apenas HTML e CSS, com foco em um visual dark, moderno e minimalista. O projeto foi criado para representar minha identidade como desenvolvedor e apresentar meus principais trabalhos de forma clara e elegante.

    O layout foi construído do zero, com atenção à tipografia, hierarquia visual e responsividade, garantindo boa leitura e navegação em qualquer dispositivo. Cada seção foi planejada para ser simples, objetiva e funcional — incluindo uma área de sobre mim, projetos e informações de contato.

    Este projeto demonstra minha capacidade de:

  • Estruturar páginas sem frameworks
  • Criar interfaces limpas e profissionais
  • Aplicar princípios de design moderno com CSS puro
  • Organizar código de forma clara e escalável

    • É um dos primeiros passos na construção da minha jornada como desenvolvedor, e será expandido conforme evoluo minhas habilidades.
