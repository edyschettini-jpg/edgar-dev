Projetos

Loja do JK

Loja virtual fictícia inspirada nos looks do Jungkook (BTS)

A Loja do JK é um projeto front-end desenvolvido para praticar HTML e CSS, simulando a estrutura de um e-commerce moderno. O site apresenta uma navegação simples e uma interface limpa, inspirada em lojas reais.

  • Layout totalmente responsivo
  • Header fixo com navegação intuitiva
  • Seção hero com chamada principal
  • Grade de produtos com cards estilizados
  • Formulário de contato em HTML
  • Design inspirado em e-commerces reais

Este projeto reforça conceitos como composição visual, tipografia, organização de layout e boas práticas de HTML semântico.

Edgar Dev — Site Pessoal

Este projeto marca o início da construção do meu portfólio e será constantemente atualizado conforme minha evolução.
